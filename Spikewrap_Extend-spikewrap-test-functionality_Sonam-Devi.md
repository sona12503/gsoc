#### *Synopsis*
SpikeWrap is a young project in the prototyping phase, and its test suite is currently lagging behind development. Testing the package is challenging due to its dependence on GPU hardware, SLURM scheduling, and HPC clusters. This project aims to develop a comprehensive test suite for running experimental pipelines in SpikeWrap. The test suite will systematically validate all software features, ensuring reliability in an HPC environment.
